# NEXTECH

## Descripción
NEXTECH es un sitio web estático de ejemplo para una marca ficticia de tecnología. Presenta una página de inicio, un catálogo de productos y un formulario de contacto.

## Integrantes y roles
- Integrante 1: Agustin Fretes.Rol: Desarrollo CSS y documentación..
- Integrante 2: Luciano Ledesma.Rol: Diseño y maquetación HTML.

## Cómo visualizar el proyecto
1. Descargar o clonar el repositorio.
2. Abrir la carpeta `NEXTECH`.
3. Abrir el archivo `index.html` en un navegador.
4. Desde el menú se puede navegar a Productos y Contacto.


## Plantilla tomada como referencia
Se tomó como referencia visual la plantilla gratuita **Training Studio** de TemplateMo:
https://templatemo.com/tm-548-training-studio

Se adaptó la idea general de la cabecera, navegación, secciones, tarjetas, botones y diseño adaptable. Se modificaron la temática, los colores, los textos, las imágenes y la distribución para crear una marca de tecnología. Los estilos utilizados están organizados en el archivo externo `css/estilos.css`.
